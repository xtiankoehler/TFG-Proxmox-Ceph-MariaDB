Proyecto TFG ASIR
Título
Clúster Hyperconvergente (HCI) de Alta Disponibilidad con Proxmox VE y Ceph para Servicios de Bases de Datos en Linux

Objetivo
Diseñar e implementar una infraestructura de alta disponibilidad para bases de datos utilizando software libre.

Tecnologías empleadas
Proxmox VE
Ceph
Ubuntu Server
MariaDB
GitHub
Descripción
El proyecto consiste en desplegar una infraestructura basada en Linux capaz de alojar una base de datos de forma segura y tolerante a fallos.

Para ello se utilizará Proxmox VE como plataforma de virtualización, Ceph como almacenamiento distribuido y MariaDB como sistema gestor de bases de datos.

La solución permitirá mantener el servicio activo incluso si uno de los nodos deja de funcionar.

Resultado esperado
Al finalizar el proyecto se dispondrá de una infraestructura virtualizada capaz de ofrecer continuidad de servicio gracias a la redundancia del almacenamiento y de los nodos.
